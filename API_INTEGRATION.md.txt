
Backend Base URL

https://prisma-project-tau-dun.vercel.app/

If the deployed backend URL changes, update NEXT_PUBLIC_API_URL in the frontend environment variables.

Authentication

Protected endpoints require a JWT access token.

The frontend sends the token using:

Authorization: Bearer <token>

The backend validates the token with authGuard and checks the user's role with checkRole().

Role-Based API Access

The backend protects endpoints using authGuard and checkRole().

Role

Accessible API Groups

Public

Properties, Property Details, Categories

Tenant

Rentals, Reviews, Payments

Landlord

Landlord Properties, Rental Requests

Admin

Users, Properties, Rentals

Unauthorized requests should be handled by the frontend and shown to the user with an appropriate error message.
